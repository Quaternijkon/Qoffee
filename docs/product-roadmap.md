# Qoffee 18 个月产品 Roadmap

## Summary

Qoffee 的长期定位是面向中国大陆精品咖啡用户的记录复盘专家。核心闭环是：

记录一杯 -> 复用参数 -> 复盘结果 -> 决定下一杯

资产、配方、库存、实验、学习、设备和云同步都服务这个闭环。首个交付切片是端内记录闭环 MVP；云同步优先进入后续里程碑，不在当前切片实现。

## Roadmap

### M0: 记录闭环 MVP, 2026-04 至 2026-05

- 将 `feature/records` 固定为记录工作台，首屏承载记录、草稿、库存豆子、常用配方、最近样本和复盘入口。
- 使用本地确定性 Brew Coach 规则给出下一杯建议：继续草稿、第一杯从库存开始、补完评分、高分设为配方、低分复制后微调、复用配方、补库存样本、进入复盘看趋势。
- 记录入口统一走 `RecordPrefillSource` 和草稿冲突策略。
- 不新增 Room schema，不接 AI，不实现云同步。

### M1: 大陆云同步基础, 2026-06 至 2026-08

- 默认阿里云自建：Kotlin Ktor API on ECS/ACK，RDS PostgreSQL 存结构化数据，OSS 存备份快照和附件。
- 首版邮箱登录，先内测后备案；公网发布前补齐 ICP/App 备案、公安备案、隐私政策、用户协议、注销账号和数据删除能力。
- 同步完整个人档案：档案、豆子、磨豆机、配方、记录、主观评价、风味标签、实验、指南和设置。
- 客户端新增 `SyncRepository`，本地 Room 仍是离线可用源；同步失败不阻塞记录。

### M2: 复盘到实验闭环, 2026-09 至 2026-11

- 复盘 insight 可直接转成下一步动作：复制记录、创建实验、打开高分/低分样本。
- 实验项目升级为“假设 -> 计划 -> 执行 -> 结果总结”，每个实验必须回链到记录。
- Pro 初始价值落点：高级实验模板、跨豆/跨磨豆机对比、更多图表维度和云端多设备同步。

### M3: Pro 商业化与数据可靠性, 2026-12 至 2027-02

- Free 保留完整本地记录、配方、基础复盘和本地备份。
- Pro 解锁高级复盘、实验历史、自动云备份、多设备同步和批量导出。
- 增加同步状态、备份历史、恢复演练和导出审计提示，优先保护用户数据安全。

### M4: 设备与自动采集, 2027-03 至 2027-06

- 优先接入蓝牙秤和手冲重量/流速曲线，采集结果落到记录客观参数和 `WaterCurve`。
- 设备采集先生成记录草稿，再进入复盘和实验，不新增独立设备中心作为主入口。
- Pro 能力包括设备历史曲线、冲煮偏差提示和批量导入设备日志。

### M5: 智能教练与社区前置验证, 2027-07 至 2027-10

- 在用户授权、云数据稳定、样本质量达标后推出 AI Coach beta。
- AI 建议只基于用户自己的记录生成，并给出引用样本。
- 社区只做分享卡、配方导入链接和可撤回公开内容，不做开放社区流。

## Current Slice Acceptance

- 新用户能从记录工作台在 1 分钟内开始第一条记录。
- 老用户能直接继续草稿、复用配方、复制历史记录或进入复盘。
- Brew Coach 所有写入动作在只读示范档案中禁用，详情和复盘仍可打开。
- 推荐规则有单元测试覆盖：草稿优先、库存第一杯、高分设配方、低分复制、足够样本进入复盘、最多 3 条且去重、只读写入策略。
